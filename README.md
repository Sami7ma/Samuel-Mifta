# Samuel Mifta · Portfolio

Personal portfolio website of **Samuel Mifta**, a software developer building web apps, cross-platform mobile apps and desktop systems.

**Live:** https://sami7ma.github.io/Sami7ma/

## Featured work

| # | Project | Stack |
| :-- | :-- | :-- |
| 01 | [BanKoni](https://github.com/Sami7ma/Bankoni): local-first personal finance tracker for Android and iOS | React Native · Expo · TypeScript · SQLite · Zustand |
| 02 | [AlgoVisuals](https://github.com/Sami7ma/AlgoVisuals): interactive visualizer for data structures, algorithms and OS concepts | React · Vite · JavaScript |
| 03 | [Pharmacy System](https://github.com/Sami7ma/Pharmacy-GUI): desktop suite for inventory, orders, customers and transactions | Java · Swing · SQL Server · JDBC |

## Features

- Wide editorial desktop layout that collapses cleanly on mobile
- Name in a variable serif font: the letters swell as the pointer moves near them (a gentle idle wave on touch screens)
- A dangling ID-card lanyard with contact details. Grab it and swing it, or scroll to make it sway
- AlgoVisuals opens like a portal into the live app (algovisuals-sami.vercel.app)
- Live project previews: a running bubble sort, an animated balance chart and a scanning inventory list
- "More work" section with a swipeable deck of Student Management System screenshots and a walkthrough video
- Toolbox you can filter by project (BanKoni, AlgoVisuals, Pharmacy System)
- Birana (parchment) and dark themes, remembered between visits
- Scroll progress bar in the Ethiopian colours and a copy-email button
- Respects `prefers-reduced-motion`
- Zero dependencies: plain HTML, CSS and JavaScript

## Project structure

```
index.html   page markup, project list, deck and toolbox
styles.css   design system, themes and responsive layout
script.js    theme, lanyard physics, portal, deck and toolbox filter
assets/      Student Management System screenshots and walkthrough video
```

## Run locally

No build step is needed. Open `index.html` in a browser, or serve the folder:

```bash
npx serve .
```

## Deploy

Push to a GitHub repository and enable **GitHub Pages** (Settings → Pages → deploy from the `main` branch, root folder).
